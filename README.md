# 🌱 Intelligent Pesticide Sprinkling System

## 📌 Project Overview

The Intelligent Pesticide Sprinkling System is a smart agriculture-based application designed to identify plant diseases using machine learning and provide suitable pesticide recommendations.

The system uses a trained deep learning model to analyze plant leaf images, predict possible plant diseases, and assist users in making informed pesticide selection decisions.

## 🎯 Objectives

- Detect plant diseases through leaf image analysis.
- Use a trained deep learning model for disease prediction.
- Recommend suitable pesticides based on the detected disease.
- Promote smarter and more efficient agricultural practices.
- Reduce unnecessary pesticide usage through targeted recommendations.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning / Deep Learning:** TensorFlow / Keras
- **Web Framework:** Streamlit
- **Image Processing:** Pillow / OpenCV (as implemented)
- **Development Environment:** VS Code, Jupyter Notebook

## ⚙️ Key Features

- Plant leaf image upload.
- Automated plant disease prediction.
- Disease-based pesticide recommendations.
- Interactive Streamlit user interface.
- Machine learning model integration.

## 🧠 Machine Learning Workflow

1. Collect and prepare plant leaf image data.
2. Preprocess images for model training.
3. Train the deep learning model.
4. Evaluate the model using test images.
5. Load the trained model into the Streamlit application.
6. Predict plant diseases from uploaded images.
7. Display relevant pesticide recommendations.
